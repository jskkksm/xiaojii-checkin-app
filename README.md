# 小迹打卡

一款为 vivo X300 等竖屏 Android 手机设计的日常打卡 PWA。无需注册和登录，可以自己打卡，也可以创建小组邀请同事一起打卡。

## 已有功能

- 运动、喝水、阅读、早睡等默认习惯
- 次数/时长累计打卡与一次完成打卡
- 自定义习惯名称、图标、颜色、目标和每次记录值
- “今天做了什么”文字备注
- 今日进度、连续天数、累计能量、最近七天图表与月历
- 每日详情、最近记录、习惯管理
- 创建打卡小组、6 位邀请码、分享链接
- 同事输入昵称即可加入，不需要注册账号
- 今日同行榜、小组完成总量、本周能量和小组动态
- 在线状态独立显示，可随时隐藏；在线不代表已经打卡
- 小组聊天、快捷打气语句和打卡自动消息
- 群聊和私聊都支持系统表情、自定义表情和手机相册图片
- 自定义表情可拖动、缩放并叠加文字后保存；已发送文字消息可以编辑
- 点击排行榜中的同事可打开一对一私聊；私聊不会出现在群聊
- “小组火花”：至少两位同事当天完成打卡即可点亮，并累计连续天数
- 小组打卡自动同步；断网打卡会在联网后补同步
- 学生专区：25 分钟专注计时、背单词、作业、错题复习快捷模板
- 学生小名片：昵称、学校/班级、学习宣言
- 5 套静态壁纸，也可以从相册选择自己的竖屏壁纸
- 头像建议 `512 × 512`，小名片封面建议 `1080 × 608`，两张图片独立保存
- 点击顶部头像可从相册更换头像，并同步用于个人名片左侧的小头像
- 流光青焰、太极星阵、金光燃动 3 套实时动态壁纸
- 青绿、雾蓝、鎏金 3 种静止边框，头像框不会旋转或闪烁
- 今日、同行、记录、我的四个板块可分别上传图片并独立裁剪
- 我的名片支持 MP4/WebM 动态背景，可手动开启原声
- 同事名片页可查看当前状态、个人签名和最近团队打卡
- 动态装扮通过累计打卡天数或运动分钟解锁，并显示个人成长进度
- 震动反馈、昵称修改
- JSON 数据导出与恢复
- PWA 离线缓存，可添加到 Android 桌面
- 适配全面屏安全区、竖屏手势区和 320-520px 手机宽度

## 在本机预览

在 `checkin-app` 目录运行：

```powershell
node server.js
```

电脑访问 `http://localhost:4173`。同一 Wi-Fi 下的手机也可以访问终端显示的局域网地址，但 Android 只有通过 HTTPS 或 localhost 打开时才支持完整 PWA 安装和离线能力。

直接双击 `index.html` 可以使用个人打卡，但不具备小组同步和完整离线安装能力。

## 安装到 vivo X300

共享小组需要 Node.js 服务端和持久化磁盘，不能只上传到普通静态网页空间。可以部署到 Railway、Render、Fly.io、云服务器或任何支持 Docker/Node.js 的平台。

1. 使用本目录的 `Dockerfile`，或将项目作为 Node.js 服务部署。
2. 设置持久化数据目录 `DATA_DIR`，例如 `/data`，避免服务重启后小组数据丢失。
3. 为网站启用 HTTPS，并记下公网网址。
4. 在手机上优先使用 Chrome 打开这个 HTTPS 网址。
5. 点击浏览器菜单中的“安装应用”或“添加到主屏幕”。
6. 在“同行”页创建小组，再点“分享链接，邀请同事加入”。

当前局域网预览地址（`http://192.168.x.x:4173`）只适合同一 Wi-Fi 下的测试。电脑关机或离开同一网络后，链接会失效，也不能通过公网分享给同事。

也可以使用 Docker：

```powershell
docker build -t xiaojii-checkin .
docker run -d -p 8080:8080 -v xiaojii-data:/data --name xiaojii-checkin xiaojii-checkin
```

然后访问 `http://localhost:8080`。正式分享给同事时仍需通过带 HTTPS 的公网域名访问。

## 同事如何加入

1. 小组创建者在“同行”页点“分享链接，邀请同事加入”。
2. 把链接发到工作群。链接内已经带上 6 位邀请码。
3. 同事打开链接、填写昵称即可加入，无需安装后才能参与。
4. 同事安装 PWA 后，在手机上打卡会自动同步到小组。

同事不需要接收 APK 或整个项目文件夹。部署到公网后，直接发送页面邀请链接即可；对方用 Chrome 打开链接，就能加入小组，之后可以在浏览器菜单中“安装应用”或“添加到主屏幕”。

邀请码只适合内部轻量协作，不要把它当作企业级账号或敏感信息保护机制。

## 数据说明

个人习惯和历史明细默认保存在当前手机浏览器的 `localStorage` 中。加入小组后，只有当天参与小组的打卡项目、进度和备注会同步到服务端，供同组成员查看。

服务端小组数据默认保存在 `.data/teams.json`，请给 `DATA_DIR` 挂载持久化磁盘并定期备份。服务端只保存成员昵称的哈希令牌，不保存明文访问令牌。

清理浏览器网站数据、卸载浏览器或更换手机可能导致本地个人记录丢失，建议定期在“我的 → 导出备份”中保存 JSON 文件。

## 文件说明

- `index.html`：应用界面
- `styles.css`：手机端视觉与响应式布局
- `app.js`：打卡、统计、数据备份等交互逻辑
- `server.js`：静态页面服务和共享打卡 API
- `manifest.webmanifest`：PWA 安装信息
- `sw.js`：离线缓存
- `Dockerfile`：用于公网部署的容器配置
- `icons/`：桌面图标
- `previews/`：390px 手机尺寸效果图
